# Gellings Christmas Song microsite

This folder is designed to be copied into `Gellingsiom/Christmas-2026` as `christmas-song/`.

## Publish with GitHub Pages
1. Upload the entire `christmas-song` folder to the repository.
2. In the repository, open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Wait for the Pages deployment to finish.

If GitHub Pages is already enabled for the repository, the page will be at:
`https://gellingsiom.github.io/Christmas-2026/christmas-song/`

A QR code should be generated only after the live page URL has been confirmed.
